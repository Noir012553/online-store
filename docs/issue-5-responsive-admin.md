# Issue 5: Responsive giao diện admin

## Mục tiêu

Giúp các trang admin sử dụng tốt trên desktop, tablet và mobile mà vẫn giữ nguyên màu sắc, typography, hình dạng, biến style, breakpoint và logic nghiệp vụ hiện có.

## Đã hoàn thành

- Admin layout có sidebar mobile, overlay, trạng thái mở/đóng và bố cục theo breakpoint.
- Products, Orders, Customers và Coupons có bộ lọc responsive, bảng cuộn ngang có kiểm soát và cột thao tác sử dụng được.
- Product, Order, Customer và Coupon form chuyển về một cột trên mobile.
- Dashboard, Statistics, Banners, Currency, Translations và các bảng admin phụ đã được rà soát.
- Giữ nguyên API, route, phân quyền, validation và dữ liệu.

## Còn lại

- Cần kiểm tra thao tác trực tiếp trên preview ở desktop, tablet và mobile.
- Cần kiểm tra golden path của Dashboard, Products, Orders và Customers khi môi trường preview sẵn sàng.

## Trạng thái

**Hoàn thành phần triển khai responsive; còn xác minh trực tiếp trên preview.**
